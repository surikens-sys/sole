# 솔솔 소개팅 연습

연애 경험이 없는 사람이 소개팅 대화를 선택지로 연습하는 웹 프로그램입니다.
시작 전에 상대의 이름, 직업, MBTI를 고르고, 상대의 말에 답 6개 중 하나를 고르면
상대의 반응과 코치 한 줄 피드백이 나옵니다.

- 상대 이름 5개: 지수, 서연, 하은, 민지, 유나 (무작위 가능)
- 상대 직업 4개: 출판사 편집자, 간호사, 비서, 백수 (무작위 가능)
- 상대 MBTI 16개 전부 (무작위 가능), 상대의 말도 MBTI 성향에 맞게 바뀜
- 내 MBTI 16개 전부 (무작위 가능), 내 MBTI 네 글자 중 두 글자를 골라 맞춤 연습 질문이 나옴
- 연습 문제 61개: 첫인사 14 · 대화 중간 20 · 마무리 4 · 직업별 4 · MBTI 질문 1 · MBTI 후속 10 · 내 MBTI 맞춤 8
- 질문마다 답 6개 (좋아요 2 · 괜찮아요 2 · 아쉬워요 2), 순서는 매번 섞임
- 한 번 연습할 때 10개: 첫인사 1 → (직업 1 · MBTI 2 · 내 MBTI 맞춤 2 · 중간 3 을 섞어서) → 마무리 1

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인 |
| `questions.js` | 직업, MBTI, 연습 문제 (내용을 바꾸려면 이 파일만 고치면 됨) |
| `app.js` | 상대 고르기, 무작위 뽑기, 대화 진행 |

## 내 컴퓨터에서 실행

`index.html` 을 더블클릭하면 브라우저에서 열립니다. 설치할 것은 없습니다.

## 사이트에 올리기

서버 프로그램이 필요 없는 정적 사이트라서, 이 폴더의 파일 4개를 그대로 올리면 됩니다.

**Netlify Drop (가장 쉬움)**
1. https://app.netlify.com/drop 에 접속해 로그인
2. 이 폴더를 통째로 끌어다 놓기
3. 나오는 주소(`https://○○○.netlify.app`)로 접속

**GitHub Pages**
1. GitHub에 새 저장소를 만들고 파일 4개를 업로드
2. 저장소의 Settings → Pages → Branch 를 `main` 으로 선택하고 Save
3. 잠시 뒤 `https://아이디.github.io/저장소이름/` 으로 접속

## 고친 내용이 사이트에 안 보일 때

브라우저가 예전 파일을 최대 10분까지 기억합니다. `style.css`, `questions.js`, `app.js` 를 고쳤다면
`index.html` 에서 `?v=4` 같은 번호를 하나 올려주세요 (예: `?v=5`). 바로 새 파일을 받아옵니다.

## 문제 추가·수정

`questions.js` 를 열어 같은 모양의 블록을 복사해 붙이고 글자만 바꾸면 됩니다.
`grade` 는 `good`, `ok`, `bad` 중 하나로 적습니다.
글 안에 `{name}` 은 상대 이름, `{nameIs}` 는 "서연이에요/지수예요", `{mbti}` 는 상대 MBTI,
`{mbtiLine}` 은 그 MBTI 소개 한 줄로 바뀝니다. 이름을 늘리려면 `NAMES` 에 추가하면 됩니다.
직업을 추가하려면 `JOBS` 와 `JOB_TALK` 에 같은 이름(예: `teacher`)으로 하나씩 넣으면 됩니다.
